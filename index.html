💡 How These Apps Help Justin's Brain Learn

Research-backed strategies implemented specifically for ADHD, dyscalculia, and working-memory challenges:

🧩 Concrete → Pictorial → Abstract

Instead of forcing Justin to manipulate abstract digits mentally, we provide physical representations (ten-frames for making 10, rods for tens, frog hops for jumps). The brain grounds the number physically first.

🎧 Dual-Coding (Visual + Verbal)

Listening to a calm verbal explanation while visually seeing counters move bypasses dyslexia and working memory bottlenecks, doubling cognitive retention.

⚡ Dopamine-Driven Low Friction

ADHD brains crave immediate feedback and shut down under punitive stress. Here, questions appear one at a time, mistakes give gentle hints with zero score penalty, and streaks award XP celebration!

🌐 How to Host Both Applications on GitHub Pages

Both applications are 100% self-contained static web applications with zero build steps or external dependencies. To host them publicly on your GitHub for free:

  1. Push this folder to a GitHub repository:
    git init • git add . • git commit -m "Initial commit of Justin Maths Grade 7" • git push origin main
  2. On GitHub, go to your repository's Settings tab.
  3. Click Pages in the left sidebar under "Code and automation".
  4. Under Build and deployment > Branch, select main and folder / (root), then click Save.
  5. Within 1-2 minutes, GitHub Pages gives you a live URL (e.g. https://yourusername.github.io/reponame/) where Justin can access both apps on any PC, iPad, tablet, or phone!
